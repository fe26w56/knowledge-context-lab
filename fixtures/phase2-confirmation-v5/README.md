# Post-selection confirmation v5

This project-authored diagnostic has 20 development and 20 final questions with separate subject names and operational facts. Both existing retrieval configurations were fixed before these questions were authored. The author has seen the implementation and earlier responses. This is an additional confirmation exercise, not an independent benchmark or an untouched external holdout.

Every paragraph and complete table is indexed, including content that is not an expected answer. There is no gold-only section filter, answer-marker paragraph, or repeated generic prose added to inflate compression. Documents are concise operational notes; twelve-row matrices exercise units, thresholds and exceptions. The same schema assigns state and validity to sections. Historical dates fall inside the referenced version's validity interval. Drafts and rejected proposals remain labelled. Private records have separate adopted shared access policies and consistent actor identities.

The initial source and questions are hash-frozen before any retrieval or model run. Independent task-local semantic review and root structural review are required before acceptance. Preserve rejected v1 and v2; do not overwrite them. Corpus expansion uses the existing generator and must be described as synthetic. Larger corpora and repetitions do not add independent questions.

V4 repairs the pre-measurement semantic audit findings and a historical record-time issue; the unmeasured v3 draft is preserved.

V5 encodes rejected drafts as proposed (non-adopted) in the existing schema. Their rejection disposition is explicit in their bodies. V4 failed the runtime schema before retrieval; no metric or model output was obtained.
