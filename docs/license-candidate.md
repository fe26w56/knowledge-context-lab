# ライセンス候補と公開前の確認

履歴文書: 下記は初回Phase 2時点の状態。0.3.0rc1のローカル配布候補には `LICENSE` としてMIT本文を同梱した。受領ZIPの再配布権確認と外部公開は引き続き未実施。[現在の来歴](release-provenance.md)を参照。

コードと架空データを再利用しやすくする候補は MIT License。現段階では未採択であり、この文書はライセンスの付与ではない。

公開前に、受領した Phase 1 ZIP のコード・架空データについて公開・再許諾の権利を確認し、権利者がライセンスと著作権表記を確定する。tiktoken 等の第三者パッケージとエンコーダーデータは配布ZIPに同梱しない。導入時に依存元から取得する。

今回の成果物はローカルのレビュー候補。GitHub公開、本番移行、第三者への送付は実施していない。公開判断の条件は、ライセンス確定、同梱物の再確認、再現コマンドの第三者環境での確認である。
